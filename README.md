\# SafeDrive AI

\### AI-Powered Road Safety and Collision Risk Warning System



\## 1. Project Overview

SafeDrive AI is a road safety prototype designed to demonstrate

how driving conditions can be used to identify potential road risks

and provide timely warnings to drivers.



\## 2. Problem Statement

Road accidents can occur due to excessive speed, poor weather,

unsafe road conditions, and insufficient distance from hazards.

Drivers need clear warnings to help them make safer decisions.



\## 3. Proposed Solution

SafeDrive AI combines driving-risk calculations, stopping-distance

estimates, map visualization, and emergency SOS message generation

in one dashboard.



\## 4. Key Features

\- Driving risk score and risk level

\- Speed and weather condition analysis

\- Road condition assessment

\- Approximate stopping-distance estimate

\- Map with a simulated vehicle location

\- Emergency SOS message generation

\- Interactive dashboard



\## 5. Technology Stack

\- Python

\- Streamlit

\- Folium

\- Streamlit-Folium

\- Pyttsx3



\## 6. Project Modules

\- app.py: Main application and dashboard

\- risk\_engine.py: Risk calculations

\- map\_module.py: Map visualization

\- emergency\_module.py: SOS message generation

\- requirements.txt: Python dependencies



\## 7. Current Limitations

This prototype uses simplified, rule-based calculations and

simulated location data. It does not use live vehicle sensors,

live GPS, real-time weather data, or a trained machine-learning model.

The SOS feature generates a message but does not contact emergency

services automatically.



\## 8. Future Enhancements

\- Live GPS integration

\- Real-time weather information

\- Vehicle sensor integration

\- Validated collision-risk models

\- Emergency contact integration

\- Machine-learning-based risk prediction



\## 9. Disclaimer

SafeDrive AI is an educational prototype and must not be relied

upon as a real-world vehicle safety or emergency-response system.
